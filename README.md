## Sobre mim

Sou engenheiro de software em Goiânia, GO. Minha trajetória começou na logística, onde aprendi na prática como processos manuais custam tempo e dinheiro. Hoje uso tecnologia para resolver exatamente esses problemas.

Em outubro de 2026 fundei a **HStack**, empresa de engenharia de software focada em automação e soluções tecnológicas sob medida.

---

## HStack

> Engenharia de software aplicada a problemas reais de negócio.

A HStack projeta e desenvolve sistemas que eliminam trabalho repetitivo, integram ferramentas e dão clareza para quem toma decisões.

| Serviço | O que entregamos |
| :-- | :-- |
| **Automação de processos** | Fluxos que substituem tarefas manuais e reduzem erros |
| **Sistemas sob medida** | Aplicações web e APIs desenhadas para a operação do cliente |
| **Integrações** | Conexão entre sistemas, plataformas e fontes de dados |
| **Consultoria técnica** | Diagnóstico e arquitetura para escolher a solução certa |

**Quer automatizar algo na sua empresa?** Fale comigo pelo [LinkedIn](https://linkedin.com) ou pelo [Instagram](https://www.instagram.com/hiago.swe/).
